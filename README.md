# Collagio privacy policy

The public privacy policy for Collagio, the story and collage maker for Android, served by GitHub Pages:
https://raoabdullahworkzone.github.io/collagio-privacy/

`index.html` is generated from the app's own strings (`tools/privacy/generate_policy.py` in the app repository), so it says the same as Settings › Privacy policy in the app. Edit the strings there and regenerate; don't edit this page by hand.
